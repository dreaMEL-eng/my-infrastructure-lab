# Hybrid Infrastructure Project (On-Prem + Azure)

## Overview
This project describes my understanding and practical exposure to hybrid infrastructure combining on-premises VMware environments with Microsoft Azure cloud services.

---

## On-Prem Environment (VMware)
- Virtual machine creation and management using VMware
- Windows Server and Linux server installation
- Network configuration (NAT, Bridged, Internal networks)
- Storage and resource allocation (CPU, RAM, Disk)
- Snapshot management and basic recovery

---

## Cloud Environment (Microsoft Azure)
- Deployment of Virtual Machines in Azure
- Virtual Network (VNet) and subnet configuration
- Storage accounts and basic cloud storage concepts
- Network Security Groups (NSG) for access control
- Basic Azure Active Directory (Entra ID) concepts

---

## Hybrid Concept Understanding
- Difference between on-prem and cloud infrastructure
- Basic idea of workload migration from VMware to Azure
- Importance of disaster recovery and backup strategies
- Concept of secure connectivity between on-prem and cloud (VPN/Hybrid connection)

---

## Goal
To develop real-world skills in designing, managing, and supporting hybrid infrastructure environments combining traditional data centers and cloud platforms.
